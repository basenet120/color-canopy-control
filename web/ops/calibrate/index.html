Check each module's wire order

Every module's lights are numbered along the cable (head 0 is the first on the wire). Painted looks and Golden Hour only land in the right place if the map below matches how VWBD actually routed each cable.

  1. Pause guest input on /ops if guests are around. Opening a module page holds that module: the canopy won't touch it until you close the page.
  2. Tap Calibrate on a module below, then on its page go to Tests → Hue ramp. Every head gets its own colour along the wire: red at head 0, then orange, yellow, green, cyan, blue and magenta at the far end (head 29).
  3. Photograph the whole module from directly below, pointing straight up, with the canopy's top edge (the plan's top) at the top of the photo.
  4. On the Calibrate tab, compare the photo with the map: the red head must be where the map shows head 0, and the colours must follow the map's wire line.
  5. If the colours run the wrong way, tap Flip wire order. If red is in a different corner or the cable runs in columns, set the start corner and cable path, then Save. If the panel hangs turned round, choose orientation B.
  6. Run the hue ramp again to confirm, close the module page (that releases it), and press Re-assert all on /ops.

Not sure about the photo? A photo taken straight up can come out mirrored left-to-right. The index sweep (Tests tab) lights one head at a time instead — slower, but it can't be misread. Both write every head individually, so on real hardware they work once bench Gate C has passed for that kit.
