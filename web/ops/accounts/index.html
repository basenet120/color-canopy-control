Sign in to an account

If Hubspace emails a code, the next page asks for it. Don't restart or redeploy the Conductor in between — that loses the sign-in and you'd have to start again. Only the refresh token is kept, encrypted; the password is never stored. This form turns itself off after one successful sign-in.

From a laptop, run this and answer the questions (email, password, and the emailed code if asked):

python -m conductor.auth login --server … --account bench --user …

The command talks to this Conductor, which does the sign-in. To use this page instead, set CONDUCTOR_ACCOUNT_CONNECT=1 and restart; the form turns itself off again after one successful sign-in.

Devices on

    After you register a device, add its id to HUBSPACE_DEVICE_ALLOWLIST on this runtime and restart. Until then it stays read-only: nothing can write to it.
